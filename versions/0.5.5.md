# Prison Planet 0.5.5

Target: Minecraft 1.21.1 with NeoForge 21.1.77.

## Stability Fixes

- Environmental surface processing remains distributed across the ticking Condemned area, but now rotates through chunk batches rather than processing the entire simulation square every server tick.
- Sunset/night lava restoration is capped per tick, preventing large molten-stone maps from creating a single heavy block-update and save spike.
- Night cold heat-source scans occur at a bounded cadence, and cold slowness refreshes only when needed instead of continuously resending an effect.
- Cycle saved data is only dirtied when its phase changes rather than every tick.

## Generation And Rendering

- Chunk generation reuses district definitions while filling a chunk instead of regenerating identical district plans for every surface column.
- Suspended Brine now includes its missing fluid-block model mappings, and the Condemned portal includes an item model, eliminating the Prison Planet model warnings observed in the test log.
