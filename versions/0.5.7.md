# Prison Planet 0.5.7

Target: Minecraft 1.21.1 with NeoForge 21.1.77.

## Safe Houses

- Safe-house placement now uses `7` chunk spacing with `2` chunk separation, making shelters substantially more common while retaining a minimum separation setting.
- Each safe-house attempt selects a surface shelter at weight `3` or a buried shelter at weight `2`.
- Buried shelters use the same authored structure and supplies, projected from the surface and sunk `4-20` blocks underground.
- Existing Condemned terrain is eligible for the refreshed retrofit pass using the new surface/buried distribution.

## Cloudless Hostile Sky

- Vanilla clouds are completely suppressed in the Condemned through its custom dimension-effects renderer.
- The sky now includes an authored dark red starfield/nebula backdrop and a textured, cracked molten sun layered with the existing corona glow.
- The dimension remains moonless and retains dense visible stars at night.
