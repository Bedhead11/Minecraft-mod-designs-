# Prison Planet 0.5.4

Target: Minecraft 1.21.1 with NeoForge 21.1.77.

## Landmark Generation Fix

- Safe houses, waystones, and Rustwarden keeps now use jigsaw depth `1`; depth `0` generated no initial piece in Minecraft 1.21.1 and made every attempted landmark invalid.
- Natural landmark generation now works in newly generated Condemned chunks through its registered structure sets.
- The existing-world retrofit uses the same vanilla random-spread placement calculation as each structure set, keeping old and new terrain consistent.
- The retrofit marker has been refreshed so Condemned chunks examined during the broken `0.5.3` build are considered again.

## Testing Commands

- Use `/place structure prisonplanet:safe_house`, `/place structure prisonplanet:waystones`, or `/place structure prisonplanet:rustwarden_keep` to test configured worldgen structures.
- Use `/place template prisonplanet:waystone1` or `/place template prisonplanet:waystone2` to test either individual authored waystone template.
