# Prison Planet 0.4.0

Target: Minecraft 1.21.1 with NeoForge 21.1.77.

## Native Creature Roster

This release adds twelve Condemned species, each with its own entity texture atlas, cubic model layer, renderer, spawn egg, loot table, attributes, and behavioral identity.

| Creature | Disposition | Spawn rule | Behavior | Hazard status |
| --- | --- | --- | --- | --- |
| Ash Stalker | Hostile | Dark only | Fast leaping ambusher; intermittent blindness strike | Vulnerable |
| Chain Wretch | Hostile | Dark only | Door-opening pursuer; slowing chain blows | Vulnerable |
| Frost Wraith | Hostile | Dark only | Avoids sunlight; rapidly freezes targets | Immune |
| Vent Crawler | Hostile | Dark only | Low, sprinting leaper; poisonous bite | Vulnerable |
| Cage Phantom | Hostile | Dark only | Sun-avoiding cage specter; weakness attack | Vulnerable |

| Salvage Porter | Passive | Any light | Armored scavenger attracted to ferric scrap | Vulnerable |

## Integration

- The Condemned biome now defines populations for all twelve species, and the dimension generator now returns biome mob settings instead of suppressing natural spawning.
- Six hostiles and one passive use darkness-constrained spawn placement; three hostiles patrol without a darkness restriction.
- Native vulnerable mobs participate in direct-sky day burning and exposed night freezing. `Frost Wraith`, `Furnace Warden`, and `Glacial Drifter` are exempt from these dimension hazards.
- Spawn eggs appear in the existing `The Condemned` creative inventory group for testing.

## Visual Assets

- Twelve dedicated 64x64 pixel entity texture atlases use distinct soot, rust, ember, frost, hazard-red, or salvage palettes.
- Twelve separate cubic mesh definitions provide unique silhouettes: bipeds, quadrupeds, crawler, suspended cage form, and winged drifter.
- The generated texture catalogue preview is stored at `prisonplanet/reference/condemned_mob_textures_0.4.0.png`.

## Existing Features Retained

The material expansion, hazard cycle, sky-exposure behavior, lava restoration, heavy night snow, custom hostile sky, Nether-style portal, and seeded megastructure terrain remain included.
